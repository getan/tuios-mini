# v0.10.38

This is a rollback patch for v0.10.37.

v0.10.37 filtered the Kitty keyboard capability query on SSH hosts. That
prevented the late `CSI ? 5u` reply, but it also disabled the keyboard
enhancement negotiation and made input unreliable. Do not use v0.10.37.

v0.10.38 is source-equivalent to v0.10.36 for the affected code and restores
the normal input path. The SSH `5u` reply remains a known issue in this patch;
it will be addressed without disabling keyboard enhancements.
