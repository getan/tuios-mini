# v0.10.43 — Short, layered Agent-control menus

The pane context menu no longer repeats a long project/role label once per scope.
Its first level now shows only the current controller, **Agent control…**, and
revoke. Agent control opens a short two-step flow:

1. choose the live Agent by project/role;
2. choose **Next action** or **This conversation**.

The current scope is rendered as a right-hand hint. Transfer confirmation shows
the old and new controller on separate rows and uses a short **Confirm transfer**
action, so narrow terminals no longer hide the important distinction behind an
ellipsis. Candidate revalidation, direct-menu provenance, exclusivity and lease
consumption are unchanged.
