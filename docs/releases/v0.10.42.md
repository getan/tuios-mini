# v0.10.42 — Atomic pane-controller leases on Windows

The Golder pane-control registry now uses an exclusive `LockFileEx` byte-range
lock on Windows. Concurrent Agent claims therefore have the same one-winner
semantics as the `flock` implementation on Unix; closing the handle, including
on abnormal process exit, releases the lock without a stale lock directory.

Other platforms and the v0.10.41 pane-menu behavior are unchanged.
